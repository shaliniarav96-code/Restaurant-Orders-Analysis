# Restaurant Orders and Delivery Analysis 🍔🚚

## 📌 Project Overview
This project analyzes online food delivery and restaurant order data to evaluate customer preferences, popular food items, delivery times, and overall service performance.

## 🛠️ Tools & Technologies Used
* **SQL / Google Sheets:** Used for writing queries, data cleaning, filtering, and calculating average delivery times and ratings.
* **Data Visualization:** Built interactive charts to showcase top-selling cuisines and peak ordering hours.

## 🔍 Key Objectives & Insights
* **Popular Cuisines:** Identified the food items and restaurant categories with the highest customer demand and orders.
* **Delivery Performance:** Analyzed delivery times to find bottlenecks and ensure timely service.
* **Customer Ratings:** Evaluated user feedback and ratings to understand customer satisfaction levels.

## 🚀 Conclusion
The insights from this analysis help restaurant managers improve food preparation times, optimize delivery routes, and enhance overall customer experience.
